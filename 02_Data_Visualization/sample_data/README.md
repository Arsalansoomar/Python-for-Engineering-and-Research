# Sample Data

This folder contains small synthetic datasets for the Python data-visualization examples.

## Files

### `voltage_current.csv`
Time-domain voltage, current, and power data.

**Use for:** basic line plots, multiple variables, dual-axis plots, and CSV plotting.

### `multiple_cases.csv`
One time axis with four comparable voltage cases.

**Use for:** multiple line plots, loop-based plotting, legends, and engineering case comparison.

### `fft_example.csv`
Synthetic frequency-domain data from 10 kHz to 30 MHz for one baseline and three comparison cases.

**Use for:** logarithmic frequency axes, FFT/spectrum plots, multiple-case comparison, and publication-style figures.

### `converter_measurements.xlsx`
Excel workbook containing three worksheets:

- `Time_Domain` — voltage, current, power, efficiency, and temperature versus time.
- `Load_Sweep` — converter performance versus load.
- `Case_Comparison` — frequency-domain comparison data.

**Use for:** reading Excel files, selecting worksheets and columns, plotting several variables, and comparing engineering datasets.

> These datasets are synthetic and intended only for learning, code testing, and plotting demonstrations.
